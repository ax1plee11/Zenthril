# Backup & Restore

- Ежедневно сохранять контролируемый экспорт проверенных данных и манифестов.
- Для полного восстановления — корректный backup/dump по редакции Neo4j.
- Community Edition не предоставляет Enterprise-only online backup.
- Тестировать восстановление на отдельной БД; проверять хэш релиза, индексы и число сущностей.
- Rollback: вернуть active_release_id к прошлому approved релизу, не удаляя новый.
- Плановый тест восстановления не реже одного раза в месяц; RPO/RTO согласовать.
