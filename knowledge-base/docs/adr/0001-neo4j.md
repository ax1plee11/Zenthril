# ADR 0001: Добавление Neo4j как отдельного модуля знаний VERIX

## Статус
Принято (проектное ТЗ, версия 1.0, 05.11.2026)

## Контекст
VERIX требует управляемого графа знаний о классах уязвимостей (CWE), категориях рисков (OWASP), способах проверки и рекомендациях по исправлению. Текущий бэкенд использует PostgreSQL для проектов, сайтов, находок и истории проверок. Neo4j добавляется как отдельный граф знаний, не заменяя PostgreSQL.

Главное архитектурное решение: PostgreSQL остаётся основным хранилищем VERIX; Neo4j используется только для знаний, чтение через read-only KB Gateway, запись только из управляемого ETL и админ-процесса.

## Решение
- Добавить Neo4j Community Edition в docker-compose (отдельный сервис, том neo4j_data, сеть zenthril-internal, порты только на 127.0.0.1).
- Графовая модель: Weakness, RiskCategory, Vulnerability, RuleRevision, DetectionSignal, Mitigation, Technology, SourceRecord, KnowledgeRelease.
- Типизированные отношения: IN_CATEGORY, ASSOCIATED_WITH, ASSESSES, DETECTS, EXPECTS, APPLIES_TO, ADDRESSES, SUPPORTS, INCLUDES.
- ETL-конвейер из 6 стадий: Acquire → Validate → Normalize → Link & dedupe → Review → Publish.
- KB Gateway на FastAPI: read-only эндпоинты /internal/kb/releases/active, /internal/kb/rules, /internal/kb/weaknesses/{id}, /internal/kb/remediations; админ-эндпоинты /internal/kb/ingest/runs, /internal/kb/releases/{id}/publish.
- PostgreSQL в Finding фиксирует kb_release_id и rule_revision_key; сканер не знает Cypher.

## Альтернативы
1. Заменить PostgreSQL на Neo4j — отклонено (не входит в MVP, исторические отчёты остаются в SQL).
2. Хранить знания только в PostgreSQL — отклонено (графовые связи и обоснования требуют графа).
3. Публичный Neo4j Browser — отклонено (раздел 1.2: не входит в MVP).

## Последствия
- Плюсы: обоснованность результатов сканирования, версионирование правил, GraphRAG для ИИ, простое добавление классов проверок.
- Минусы: дополнительная инфраструктура (Neo4j), поддержка двух хранилищ, необходимость резервного копирования графа.
- Риски: Neo4j временно недоступен → сканер использует валидированный кеш или помечает сканирование ограниченным.
