# Source Registry — источники знаний (раздел 03 ТЗ)

| Источник | Что извлекать | Приоритет | Обновление | Лицензия |
|---|---|---|---|---|
| MITRE CWE 5.0 | ID, имена, описание, Parent/Child, состояния, ссылки | P0 | версии раз в неделю | Проверить перед коммерческим распространением |
| OWASP Top 10:2025 | Категории рисков, CWE-сопоставления | P0 | при новой редакции | Бесплатно и открыто |
| OWASP WSTG 4.2 | Методики тестирования, идентификаторы, разделы | P0 | ежемесячно | CC BY-SA 4.0 (атрибуция) |
| NVD CVE API 2.0 | Релевантные CVE, CVSS, CWE, версии, modified | P1 | инкрементально по modified | Проверить условия |
| CISA KEV JSON | Признак реальной эксплуатации для CVE | P1 | ежедневно | CC0 |
| FIRST EPSS CSV | Вероятность эксплуатации, percentile | P2 | ежедневно, bulk CSV | Атрибуция EPSS |
| Ревью VERIX | Правила, сигналы, исправления, примеры | P0 | через PR и ревью | Внутренняя |

Правила сбора:
- Для каждого источника хранить URL, издателя, редакцию/версию, дату получения, SHA-256, лицензию.
- OWASP WSTG (CC BY-SA 4.0): атрибуция и проверка требований при адаптации.
- CISA KEV (CC0); FIRST просит атрибуцию EPSS.
- Предпочитать XML/CSV/JSON/API. Для HTML — уважать условия использования, не выполнять массовый скрейпинг.
- Переносить только необходимые факты и краткие аннотации; полные тексты первоисточников заменять ссылками.
