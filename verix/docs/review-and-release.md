# Review & Release

Жизненный цикл правила: Черновик → Автоматическая валидация → Ревью по безопасности → Approved → Включение в KBRelease → Retired/Deprecated.
- Любая правка утверждённого правила создаёт новую версию; опубликованный релиз не изменяется задним числом.
- Критерий активации: успешный CI, документированная граница применимости, утверждение минимум одним проверяющим, отличным от автора.
- Журнал изменений: кто, PR, reviewer, время, причина, diff; источник и версия загрузки, SHA-256, результаты валидации; изменения для сканера.
