# Changelog

All notable changes to Zenthril will be documented in this file.

## [Unreleased]

### Added
- Performance monitoring system with `/metrics` endpoint
- Prometheus-compatible metrics export
- Comprehensive benchmarking suite for Go backend
- Load testing tools using k6
- Performance analysis scripts (Python)
- Real-time metrics collection (WebSocket, HTTP, Database, Encryption)
- Research tools for academic use
- Multi-language support (EN, RU, UK)
- Glass Minimal UI design
- Voice channels with WebRTC
- GIF support (Tenor/Giphy)
- Friend system
- Guild roles and permissions
- Message editing and deletion
- Typing indicators
- System administration endpoints

### Security
- End-to-end encryption (X25519 + AES-256-GCM)
- JWT authentication with Argon2id password hashing
- Rate limiting and DDoS protection
- Brute force protection on login
- Spam guard for messages
- Security audit logging

### Performance
- Optimized WebSocket handling
- Database query optimization with indexes
- Redis caching for sessions
- Efficient message broadcasting
- Connection pooling

## [0.1.0] - Initial Release

### Added
- Basic messaging functionality
- User authentication
- Guild (server) system
- Text channels
- WebSocket real-time communication
- PostgreSQL database
- Redis for caching
- Docker support
- Tauri desktop application
- React frontend with TypeScript
