## 3. Критические зависимости

| Зависимость | Описание | Статус |
|-------------|----------|--------|
| Доступ к production серверу | Необходим для настройки инфраструктуры | Не настроен |
| Secret Manager | Vault/AWS Secrets Manager/K8s Secrets | Не выбран |
| Внешний аудит | Бюджет и подрядчик | Не заказан |
| TLS сертификаты | Let's Encrypt или внутренний CA | Не получены |

## 4. Критерии остановки

Работа должна быть остановлена, если:

- Обнаружена критическая уязвимость, которую нельзя исправить в текущем sprint
- Отсутствует доступ к production инфраструктуре на протяжении более 2 недель
- Внешний аудит выявляет критические проблемы с E2EE
