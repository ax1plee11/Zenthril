# ZFDA NETWORK_SECURITY — Сетевая безопасность

## TLS

- Поддержка TLS через `ListenAndServeTLS` (`TLSCertFile`, `TLSKeyFile`).
- Нет принудительного перенаправления HTTP → HTTPS в коде backend.

## WebSocket

- WSS через TLS терминацию.
- Strict Origin allowlist для WebSocket upgrades.
- Одноразовые тикеты для аутентификации WebSocket.

## Сетевая сегментация

- PostgreSQL и Redis порты не publikuje наружу (только `expose` в Docker Compose).
- Доступ к БД и Redis только через внутреннюю Docker сеть.
- Backend обслуживает HTTP/WebSocket на опубликованном порту.

## Взаимодействие сервисов

- Backend → PostgreSQL: прямые соединения через pgxpool.
- Backend → Redis: прямые соединения через go-redis.
- Нет mTLS между внутренними сервисами.
- Нет сетевой сегментации между микросервисами (монолит).

## Контроль маршрутов и DNS

- Нет явного контроля внутренних DNS маршрутов.
- Federation отключена по умолчанию.

## Мониторинг аномального сетевого поведения

- Метрики WebSocket (отказы, лимиты, искаженные сообщения).
- Security event logging для IP блокировок и brute-force.
- Нет централизованного сетевого мониторинга.

## Требуется реализация

- mTLS между внутренними сервисами.
- Сетевая сегментация (отдельные сети для БД, Redis, backend).
- DNS контроль и фильтрация.
- Централизованный мониторинг сетевых аномалий.
