# ZFDA THREAT_MODEL — Модель угроз Zenthril

## Активы

1. Учетные данные пользователей и refresh токены.
2. Access токены и WebSocket тикеты.
3. Приватные ключи E2EE (identity key, signed prekey, one-time prekeys, root keys, message keys).
4. Шифротекст сообщений, IV, аутентификационные теги, протокольные метаданные.
5. Метаданные гильдий, каналов, членства, устройств, модерации.
6. Операционные токены, метрики, учетные данные БД и Redis.
7. Криптографические сеансы X3DH / Double Ratchet.

## Нарушители (угрозы)

| Нарушитель | Мотивация | Способы атаки |
|------------|-----------|---------------|
| Сетевой атакующий | Перехват, модификация трафика | MITM без TLS, подмена трафика |
| Злоумышленный сайт | CORS abuse, CSWSH | Злоумышленный Origin, WebSocket hijacking |
| Аутентифицированный пользователь | Доступ к чужим каналам, флуд | IDOR, несанкционированные API вызовы, WebSocket флуд |
| Компрометированный refresh/access токен | Захват сессии | Wiederverwendung токена, replay |
| Компрометированное устройство | Доступ к ключам и сообщениям | Кража приватных ключей, локальное хранилище |
| Компрометированный оператор сервера | Доступ к метаданным, БД | Прямой доступ к PostgreSQL/Redis, внутренние сервисы |
| Поставщик цепочки поставок | Вредоносный код | Злоумышленные зависимости, CI/CD компрометация |

## Точки компрометации

1. **JWT_SECRET** — компрометация дает подписание любых токенов.
2. **Redis** — хранение refresh токенов, blacklist, WebSocket тикетов.
3. **PostgreSQL** — пользовательские данные, ключи устройств, глобальные блокировки.
4. **Клиентская машина** — кража ключей из OS keychain, доступ к памяти процесса.
5. **Кроссплатформенная несовместимость криптографии** (F-09) — разрыв E2EE сеансов.
6. **Отсутствие MFA** — один фактор аутентификации.

## Приоритетный список проблем

1. F-09: Несовместимость криптографического материала клиент/Go (Критический)
2. F-06: MFA заявлена, но не реализована (Высокий)
3. F-05: 15 из 30 Go-пакетов без тестов (Высокий)
4. Отсутствие MFA/passkeys (Высокий)
5. Отсутствие шифрования данных при покое (Высокий)
6. Отсутствие резервного копирования и DR (Высокий)
7. Отсутствие централизованного обнаружения угроз (Средний)
8. F-04: Trivy не блокирует сборку (Средний)
