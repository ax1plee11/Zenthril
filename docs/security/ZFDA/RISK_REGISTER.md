## 5. Принятие рисков

Следующие риски принимаются как connues limitations alpha-статуса:

- **RISK-02** (E2EE не Signal-grade): Принято для alpha-статуса. Требует внешнего аудита перед production.
- **RISK-09** (Утечка метаданных): Принято как архитектурная особенность. Серверу необходимы метаданные для маршрутизации.

## 6. Ежемесячный обзор

Реестр рисков должен пересматриваться ежемесячно и при каждом значительном изменении архитектуры.
