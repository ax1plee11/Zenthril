# ZFDA ASSET_INVENTORY — Инвентарь активов Zenthril

## Категория: Учетные данные и аутентификация

| Актив | Местоположение | Классификация | Владелец | Защита |
|-------|---------------|---------------|----------|--------|
| Пароли пользователей (argon2id hash) | PostgreSQL `users.password_hash` | Секретный | Backend | Argon2id, параметризованные запросы |
| Access JWT токены | Память клиента, Redis blacklist | Секретный | Auth сервис | HS256, TTL 15 мин, blacklist |
| Refresh токены | Redis `refresh:jti:*`, `refresh:user:*` | Секретный | Auth сервис | SHA-256 хеш, rotation GETDEL, replay detection |
| WebSocket тикеты | Redis `ws:ticket:*` | Секретный | Auth сервис | Одноразовые, TTL 2 мин, GETDEL |
| JWT_SECRET | Переменная окружения | Критический | Backend | Не в коде, fail-closed валидация |

## Категория: Криптографические ключи

| Актив | Местоположение | Классификация | Владелец | Защита |
|-------|---------------|---------------|----------|--------|
| E2EE identity private key | OS keychain клиента | Критический | Клиент | Windows Credential Manager / macOS Keychain / Linux Secret Service |
| E2EE signed prekey | PostgreSQL `devices` | Секретный | Device сервис | Подпись Ed25519, валидация при регистрации |
| E2EE one-time prekeys | PostgreSQL `device_one_time_prekeys` | Секретный | Device сервис | Потребление одноразово, FOR UPDATE SKIP LOCKED |
| Root keys, message keys | Память клиента | Критический | Клиент | Не передаются на сервер |
| Ed25519 signing identities | Клиент | Критический | Клиент | Локальное хранение |

## Категория: Пользовательские данные

| Актив | Местоположение | Классификация | Владелец | Защита |
|-------|---------------|---------------|----------|--------|
| Профили пользователей | PostgreSQL `users` | Внутренний | Backend | RBAC, параметризованные запросы |
| Сообщения (шифротекст) | PostgreSQL `messages` | Секретный | Message сервис | AES-256-GCM, E2EE, сервер не расшифровывает |
| Метаданные сообщений | PostgreSQL | Внутренний | Backend | Контроль доступа, аудит |
| Гильдии, каналы, членство | PostgreSQL | Внутренний | Guild сервис | RBAC v2, проверка доступа к каналу |
| Глобальные блокировки | PostgreSQL `global_bans` | Внутренний | Auth сервис | Админ-only, проверка при WS подключении |

## Категория: Инфраструктурные секреты

| Актив | Местоположение | Классификация | Владелец | Защита |
|-------|---------------|---------------|----------|--------|
| PostgreSQL пароль | Переменная окружения / Docker secret | Секретный | Операции | Не в коде, не publikuje |
| Redis пароль | Переменная окружения | Секретный | Операции | Не в коде |
| METRICS_TOKEN | Переменная окружения | Секретный | Операции | Обязателен в production |

| FEDERATION_TOKEN | Переменная окружения | Секретный | Операции | Требуется при federation enabled |

## Категория: Аудитные логи

| Актив | Местоположение | Классификация | Владелец | Защита |
|-------|---------------|---------------|----------|--------|
| Security log | PostgreSQL `security_log` | Внутренний | Security Guard | Без паролей, токенов, приватных ключей, содержимого E2EE |
