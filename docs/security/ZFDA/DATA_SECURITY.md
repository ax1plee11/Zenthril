# ZFDA DATA_SECURITY — Защита данных

## Контроль доступа к данным

- RBAC v2 для гильдий и каналов.
- Проверка доступа к каналу перед чтением/записью сообщений.
- Публичные устройства: минимизированная проекция, требуется общая гильдия.
- Поиск пользователей: валидация запроса, пустой результат при ошибках валидации.

## Защита PostgreSQL и Redis

- PostgreSQL: параметризованные запросы (pgx), пользователь с ограниченными правами.
- Redis: изоляция в Docker сети, отдельные пространства ключей.
- Порты БД и Redis не publikuje наружу.

## Шифрование данных

- **При передаче:** TLS (если настроены сертификаты).
- **При покое:** Нет шифрования данных в PostgreSQL и Redis. Требуется реализация.

## Резервные копии

- Нет настроенного резервного копирования.
- Нет проверки восстановления из резервных копий.
- Docker volumes (`postgres_data`, `redis_data`) не бэкапятся автоматически.

## Контроль целостности

- AES-GCM предоставляет аутентификацию шифротекста.
- Параметризованные запросы предотвращают SQL injection.
- Нет контрольных сумм для файлов базы данных.

## Безопасное удаление данных

- Отзыв устройства удаляет one-time prekeys.
- Глобальная разблокировка удаляет запись из `global_bans`.
- Нет криптографического стирания (cryptographic erasure).
- Нет безопасного удаления резервных копий.

## Защита WAL и чувствительных файлов

- Нет специальной защиты WAL файлов PostgreSQL.
- Нет шифрования файлов базы данных на диске.
