# ZFDA ATTACK_SURFACE — Поверхность атак Zenthril

## Внешняя поверхность (интернет / клиент)

| Вектор | Компонент | Уязвимость | Статус защиты |
|--------|-----------|------------|---------------|
| HTTP API регистрации | `auth.Register` | Брутфорс, перебор паролей | Rate limiting, brute-force защита |
| HTTP API входа | `auth.Login` | Брутфорс, credential stuffing | Rate limiting, brute-force защита (10 попыток → блок 15 мин) |
| HTTP API refresh | `auth.Refresh` | Реплей refresh токена | GETDEL, отзыв всех токенов при детекте replay |
| WebSocket подключение | `hub.ServeWS` | CSWSH, реплей тикета | Origin валидация, одноразовые тикеты |
| WebSocket сообщения | `hub.readPump` | Флуд, искаженные команды | Лимиты сообщений, проверка типа, порог искажений |
| Отправка сообщений | `message.SendMessage` | Инъекция, несанкционированный доступ | Спам-guard, проверка доступа к каналу |
| Регистрация устройства | `device.RegisterDevice` | Превышение лимита, подмена ключей | Лимит 10 устройств, Ed25519 подпись, X25519 валидация |
| Claim key bundle | `device.ClaimKeyBundle` | Исчерпание prekey, доступ к чужим ключам | FOR UPDATE SKIP LOCKED, проверка общей гильдии |
| Публичные устройства | `device.ListUserDevicesPublic` | Убор ключевого материала | Общая гильдия, минимизированная проекция |
| Поиск пользователей | `user.Search` | Перебор, enum | Валидация запроса, пустой результат при ошибках валидации |

## Внутренняя поверхность (серверная инфраструктура)

| Вектор | Компонент | Уязвимость | Статус защиты |
|--------|-----------|------------|---------------|
| Backend → PostgreSQL | `db.Open` | SQL injection | Параметризованные запросы pgx |
| Backend → Redis | `redis.NewClient` | Доступ к токенам | Изоляция в Docker сети |
| Конфигурация | `config.Load` | Секреты в коде, placeholder | Fail-closed валидация, нет хардкода секретов |
| Метрики / operational | `metricsAuth`, `operationalTokenAuth` | Анонимный доступ | Bearer токен в production |
| Federation | `federationAuth` | Несанкционированный доступ | Отключена по умолчанию, токен |
